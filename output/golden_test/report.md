- 설정이 `final_top_k=6` · `max_per_collection=2` · namespace 3개이므로 질문 성격과 무관하게 컬렉션마다 정확히 2청크가 배정됩니다.

- 정확 청크 Hit@3 35.3% vs 원천 문서 Hit@3 73.2%.
- 정답 문서가 지정된 질문 263건 중 **103건(39.2%)**은 정답 청크를 놓쳤지만 같은 질병·의약품의 **다른 섹션**은 회수했습니다.
- 예: "파킨슨병을 예방하려면?" → 정답은 `예방` 섹션인데 `정의/증상` 섹션이 회수됨. 임베딩이 질문의 **섹션 의도**(예방·원인·증상·기준)를 구분하지 못하고 질병명 유사도에 지배됩니다.

### 9.4 Intent 라우팅

- 답변불가 질문 28건 중 대부분이 `ignore`로 조기 차단되어 거절 정확도 100.0%를 기록했습니다.
- 반면 답변가능 질문 **9건(3.3%)**이 `ignore`/`general_chat`으로 잘못 라우팅되어 검색 자체가 실행되지 않았습니다. 이들의 평균 분류 신뢰도는 0.6318로 임계값 0.55를 넘어 저신뢰로 걸러지지도 않았습니다.
- 전체 저신뢰 비율은 3.3%에 불과해 현재 임계값이 오분류를 거의 포착하지 못합니다.

### 9.5 지연시간 구성

- TTFB p50 6,563ms의 최대 기여 구간은 **근거계획 생성**(p50 3,518ms)이며, 검색은 219ms, 임베딩·분류는 34ms 수준으로 무시할 만합니다.
- 사후 감사(p50 5,239ms)는 스트리밍 이후에 실행되어 TTFB에는 영향이 없지만 종단 지연 p50 10,215ms의 큰 부분을 차지합니다.

### 9.6 개선 우선순위 (제안)

| 우선순위 | 조치 | 근거 | 기대 효과 |
|---|---|---|---|
| 1 | Intent에 **대상 컬렉션 라우팅** 추가 또는 `max_per_collection` 폐지 후 점수 기반 선택 | 문맥의 66.7%가 무관 컬렉션 | 근거정밀도 대폭 개선, 근거계획 반려 감소 |
| 2 | `top_k_per_collection` 상향(3→10) + 섹션 인지 재순위화(rerank) | 섹션 불일치 39.2% | 정확 청크 Hit@k를 원천 문서 Hit@k 수준으로 근접 |
| 3 | 질병명+섹션명을 청크 임베딩 텍스트에 강화 반영하거나 하이브리드(BM25+dense) 검색 도입 | 질문의 섹션 의도가 코사인 유사도에 반영되지 않음 | 예방·원인·기준 유형 질문 회수율 개선 |
| 4 | Intent 임계값 재보정(현재 0.55) 및 장문 증상 서술 학습데이터 보강 | 답변가능 9건 오라우팅 | 불필요한 즉시 거절 제거 |
| 5 | 근거계획 프롬프트 경량화 또는 단순 질의 시 계획 단계 생략 | 계획 생성이 TTFB p50의 최대 구간(3,518ms) | TTFB 단축 |

## 11. 지표 정의

| 지표 | 계산 방식 |
|---|---|
| 근거재현율 (문서ID) | (최종문맥 ∩ `gold_document_ids`) 개수 ÷ `gold_document_ids` 개수 |
| 근거정밀도 (문서ID) | (최종문맥 ∩ `acceptable_document_ids`) 개수 ÷ 최종문맥 청크 수 |
| Hit@k | 상위 k개 문맥에 정답 문서가 1개 이상 포함되면 1 |
| MRR@10 | 첫 정답 문서 순위의 역수 평균 |
| 출처ID일치율 | LLM 근거계획이 인용한 `C{n}` → `record_id` 변환 후 정답 문서 비율 |
| 근거충실도 | ragas faithfulness — 답변 문장을 주장 단위로 분해해 문맥 뒷받침 여부 판정 |
| 정답일치율 | ragas answer_correctness — 참조 정답 대비 사실 TP/FP/FN + 의미 유사도 가중합 |
| TTFB | 요청 시작부터 사용자에게 첫 토큰이 전달되기까지 (Guard+임베딩+분류+검색+근거계획+생성 첫 토큰) |
| 거절 정확도 | 시스템 거절 여부가 골든셋 `answerable` 라벨과 일치하는 비율 |
