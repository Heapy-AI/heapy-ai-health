# 복약정보 데이터 저장 방식 논의

- 작성자: 김진우

## 질문

전처리한 의약품 목록과 병용금기 데이터를 팀이 함께 사용하려면 모두 Pinecone에 저장해야 하는가?

## 답변

- 제품명·제품 코드·성분 코드·병용금기 규칙처럼 정확한 조회가 필요한 데이터는 클라우드 RDB에 저장한다.
- 병용금기 사유를 자연어로 찾고 설명하는 청크만 Pinecone `medication_info` namespace에 선택적으로 저장한다.
- 권장 구조는 `클라우드 RDB 정확 조회 → Pinecone 설명 검색 → FastAPI 응답 조합`이다.
- 전처리 CSV는 적재 원본으로 보관하고, 팀은 공용 클라우드 DB를 통해 같은 데이터를 조회한다.

## 추후 논의

- 사용할 클라우드 RDB 결정
- 복약정보 테이블 스키마 결정
- Pinecone에 복제할 설명 청크 범위 결정
